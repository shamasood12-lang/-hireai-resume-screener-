# HireAI - Resume Screening System

HireAI is an AI-powered resume screening and candidate ranking system built using Python and Streamlit.

## Features
- Resume upload and analysis
- Keyword matching
- ML similarity scoring
- Candidate ranking
- Recruiter mode
- Resume shortlisting
- Download shortlisted resumes

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- PyPDF2
- python-docx

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
