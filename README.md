# HireAI - Resume Screening System

AI-powered resume screening and job matching system built using Python and Streamlit.

## Features

- Single Resume Analysis
- Recruiter Mode for Multiple Resume Screening
- AI-based Resume Matching
- Skill Extraction
- Match Score Calculation
- Resume Ranking System
- Shortlisting Feature
- Dark Modern UI
- PDF and DOCX Resume Support

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NLP
- Machine Learning

## Project Structure

```bash
app.py
extractor.py
matcher.py
ml_model.py
scorer.py
skills.py
resumes/
```

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
